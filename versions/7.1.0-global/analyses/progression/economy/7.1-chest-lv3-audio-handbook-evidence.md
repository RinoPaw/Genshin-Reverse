In both **252-row** investigation exports, unique row `id=60003`, `questId=6000003`, `investigationId=10001` has `triggerType=TRIGGER_OPEN_CHEST_WITH_GADGET_ID`. Its first `paramList` entry contains **88 distinct ID literals**, including all 20 core IDs and, crucially, all four `Lv3` IDs. This proves that the public client-config schema explicitly lists these IDs as accepted targets for a *chest opening* investigation trigger; it does **not** prove that a particular chest was placed, opened or paid loot in the original game.
