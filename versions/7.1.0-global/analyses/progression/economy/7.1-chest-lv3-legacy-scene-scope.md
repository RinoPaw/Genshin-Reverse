## Read-only replication

Download the earlier Actions artifact, extract its *unaltered* two files, and run:

```powershell
python scripts/audit-7.1-chest-lv3-scene-scope.py --csv .\chest-region-per-gadget.csv --summary .\chest-region-summary.json --output .\chest-lv3-scene-scope.json
python -m unittest tests.test_chest_lv3_scene_scope_71 -v
```

The script validates **both** exact artifact file SHA-256 identities, original Gadget source identity, scan provenance and counts; it reports all 20 per-ID frequencies plus the selected historical combat/puzzle ID samples. Synthetic regression tests cover zero and nonzero native ID observations, input drift and malformed IDs. No upstream game files or reward tables are rewritten.

## Remaining evidence gate

To authenticate real 7.1 placed chests, recover a **source-pinned original scene/group/config owner**, or trace official-server scene configuration against exact version evidence. Separately recover the original Gadget identity-to-claim-grade mapping and server-side drop ownership. The public `AudioBattleFervorChestTypeMapConfigData` (`Mid/Hi/Top`) and handbook chest-open whitelist are useful **client-side semantic leads** but do not prove placement, reward grades, `chest_drop_id`, drop rates or a 7.1 payout table.
