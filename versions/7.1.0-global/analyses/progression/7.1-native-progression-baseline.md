## Level-up Mora rule

Evidence: `B`.

Grasscutter's avatar-upgrade path reads `ITEM_USE_ADD_EXP`, computes the total EXP supplied by the selected books, then charges:

```
moraCost = expGain / 5
```

This matches the native ratio of 1 Mora per 5 supplied character EXP, but it has not yet been rebound to a 7.1 native client rule/table.

For exactly 8,362,650 required EXP, the theoretical Mora-equivalent is 1,672,530.

Important: an actual book combination can oversupply EXP, so the paid Mora can differ slightly depending on the exact items consumed. Keep "raw curve cost" separate from "operational book-feed cost".

## Character mapping model

Evidence: `A`.

The native chain is:

`AvatarExcelConfigData.id`
-> `avatarPromoteId`
-> `AvatarPromoteExcelConfigData.avatarPromoteId`
-> stage-specific `costItems`, `scoinCost`, level cap and ascension-stat additions.

`AvatarExcelConfigData` also supplies `qualityType`, base stats, `propGrowCurves`, `skillDepotId`, and weapon type.

Do not collapse all 4-star or all 5-star characters into a single stat template. Material IDs and ascension-stat growth remain keyed by character/promote group.

### Traveler talent exception

Evidence: `A`.

Traveler skill depots `502..508` and `702..708` use separate elemental skill sets and do not reduce to the ordinary one-book-family template.

The Traveler still uses the same **1,652,500 Mora per combat talent** and one Crown at level 10, but its talent-book IDs switch across multiple book families as levels increase.

Example: depot 502/702 uses combat ProudSkill groups `530/531`, `532`, and `539` (gender-specific normal-attack group plus shared skill/burst groups). For a single one of these talents, current 7.1 rows total:

- Mora: 1,652,500

- 104352 x12
- 104354 x4
- 104355 x20
- common-enemy materials: 112104 x6, 112105 x22, 112106 x31

The weekly-material total of **4** in this depot differs from the ordinary character total of 6.

Other Traveler elemental depots inspected use the same mixed-book pattern, but usually total 6 weekly materials. Preserve each Traveler element as its own native cost table rather than forcing it through the ordinary-character template.
