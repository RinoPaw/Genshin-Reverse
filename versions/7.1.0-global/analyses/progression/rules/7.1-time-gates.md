## Original Resin

### Capacity

Evidence: `A`.

HoYoverse's Version 4.7 update increased the Original Resin cap from 160 to **200**. This remains the known baseline entering 7.1 unless a later official change is found.

Official source used by the investigation:

- https://www.hoyolab.com/article/29513513

### Condensed Resin / multi-reward rules

Evidence: `A` from later official rule changes already reviewed by this investigation.

The old "40 Original Resin -> one Condensed Resin -> fixed double reward" rule must not be treated as the 7.1 baseline.

Confirmed later behavior recorded by the investigation:

- Condensed Resin crafting consumes **60 Original Resin**.
- Condensed Resin can be used for up to **3x** reward claiming.
- For reward claims that normally cost 20 Original Resin, the system supports spending 40 Original Resin for 2x reward, with a broader up-to-3x reward mechanism.

Official pages used by the investigation:

- https://genshin.hoyoverse.com/en/news/detail/159349
- https://genshin.hoyoverse.com/de/news/detail/166383

The exact scope of eligible reward types still needs to be normalized into a per-activity matrix.
