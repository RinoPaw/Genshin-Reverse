# Genshin Impact 7.1 Adventure Rank, World Level, and Domain rotation

Status: `PARTIAL / SOURCE-BOUND` (7.1.0 Global).

This captures rank EXP, World Level unlock flags, weekday Dungeon IDs, and talent/weapon Domain entry **previews**. It does not establish actual Domain drops, difficulty-to-reward ownership, or server-side weekday enforcement.

## Exact resource provenance

Source: [`RinoPaw/AstaPS-Resource@402e95270010`](https://github.com/RinoPaw/AstaPS-Resource/commit/402e95270010df5929f51cca8652362ca3e5c07a). Blob SHAs for each exact file are included in the two JSON snapshots.

- [`7.1-adventure-world-level.json`](7.1-adventure-world-level.json) from `PlayerLevelExcelConfigData` and `WorldLevelExcelConfigData`.
- [`7.1-daily-dungeon-schedule.json`](7.1-daily-dungeon-schedule.json) from `DailyDungeonConfigData` and `DungeonEntryExcelConfigData`.

These are evidence `A` for the present 7.1 resource rows, **not** evidence that a private server applies the rules exactly.

## Adventure Rank and World Level

In `PlayerLevelExcelConfigData`, `exp` is the cost to advance **from** that row's Adventure Rank. Rank 60 has no next-rank `exp`. AR 1 -> 60 sums to **1,880,200 raw Adventure EXP**. The cumulative series is available for every AR 1–60 in JSON.

`unlockWorldLevel` is a resource unlock field. It does **not** prove automatic World Level promotion, because ascension quests and server state can also gate progression. Likewise, `monsterLevel` is a configuration field, not a universal spawn-level guarantee. The WL9 source row additionally has `IDLGNALCKNN = -10`, whose meaning remains unknown.

## Daily Dungeon records

`DailyDungeonConfigData` contains **64 rows, IDs 17–80**. The JSON preserves the exact ordered arrays for all seven named weekdays. Every row satisfies:

- Monday = Thursday, Tuesday = Friday, and Wednesday = Saturday.
- Sunday is an independent list. **Do not** replace it with the per-row union of the other three weekdays.
- The three still-obfuscated source fields `BDJEHGHEHOE`, `MBEHIMBJEOC`, and `PJABKILGJOB` all equal the Sunday list for each row; their purpose is not yet known.

`DungeonEntryExcelConfigData` separately identifies **8 talent-material** and **8 weapon-ascension-material** entries. Their four `descriptionCycleRewardList` groups contain three item families and a fourth combined preview. For example, talent entry `10` previews IDs `104301–104309`; weapon entry `2` previews `114001–114012`. These are item-ID previews, **not drop amounts**.

There is no proven direct `DailyDungeonConfigData.id = DungeonEntryExcelConfigData.id` relationship. Do not join those tables by equal integers or infer weekday-to-material mapping without tracing the `DungeonExcelConfigData` owner.
